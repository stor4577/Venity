# Venity → постоянная ссылка на GitHub Pages

Здесь всё, что нужно для бесплатной **постоянной** ссылки на Venity. Она не зависит
от моего сервера в песочнице и от быстро умирающих туннелей: страница живёт на серверах
GitHub и открывается всегда.

**Что в папке**

| файл | что это |
|---|---|
| `index.html` | вся нейросеть целиком (9,3 МБ: модель + 1130 пар диалогов + интернет-умения) |
| `manifest.webmanifest` | чтобы приложение ставилось на домашний экран телефона |
| `icon-192.png`, `icon-512.png` | иконка приложения |
| `.nojekyll` | служебный файл: отключает обработку сайта через Jekyll (так Pages быстрее и не ломает вложения) |

---

## Способ 1 — через сайт GitHub (проще, 3 минуты, без программ)

1. Открой **github.com** → войди → кнопка **New repository**.
2. Имя репозитория: `venity` · тип: **Public** → **Create repository**.
3. На странице нового репозитория нажми **uploading an existing file**
   (или Add file → Upload files).
4. Открой папку `venity-pages` на компьютере и **перетащи в окно браузера все файлы**
   (index.html, manifest.webmanifest, icon-192.png, icon-512.png, .nojekyll)
   → внизу **Commit changes**.
   *Если `.nojekyll` при перетаскивании не видно (скрытый файл) — ничего страшного:
   потом Add file → Create new file → имя ровно `.nojekyll` → Commit changes.*
5. Зайди в **Settings** → в левом меню **Pages** →
   Source: **Deploy from a branch** → Branch: **main**, папка **/(root)** → **Save**.
6. Подожди 1–2 минуты, обнови страницу Pages — сверху появится адрес вида
   **https://ТВОЙ_ЛОГИН.github.io/venity/**

Это и есть постоянная ссылка. Открой её на телефоне:

* **iPhone (Safari):** «Поделиться» → **На экран «Домой»** → появится иконка Venity.
* **Android (Chrome):** меню ⋮ → **Установить приложение / Добавить на главный экран**.

После этого Venity открывается с иконки, как обычное приложение.

## Способ 2 — через git (если работал с git)

```bash
cd venity-pages
git init -b main
git add .
git commit -m "Venity — нейросеть офлайн + интернет-умения"
git remote add origin https://github.com/ТВОЙ_ЛОГИН/venity.git
git push -u origin main
```

Дальше так же: **Settings → Pages → Deploy from a branch → main / (root) → Save**.

## Что работает по этой ссылке

* **Нейросеть целиком внутри страницы** — отвечает без интернета. Знакомые фразы
  («привет», «как дела?», «расскажи шутку») — 1–5 мс, незнакомые — около 0,3 с.
* **Интернет-умения из браузера:** погода, курс валют, Википедия, часы
  (нужна галочка «Интернет» — она включена по умолчанию).
* **Новости** — только в серверной версии: сайт новостей не отдаёт ленту напрямую в браузер.
* Ссылка **постоянная**: обновлять ничего не надо, ничего не «засыпает».

**Про размер:** страница весит 9,3 МБ — первый раз на телефоне грузится примерно 3–10 секунд,
дальше берётся из кэша и открывается мгновенно. Если трафик дорогой — подключиться к Wi-Fi
для первой загрузки.

**Если GitHub Pages недоступен** (бывает в некоторых сетях): тот же `index.html` работает
на любом статическом хостинге — Hugging Face Static Space, Netlify (перетащить папку),
Cloudflare Pages. Локально файл тоже работает: просто открой `index.html` в браузере.
